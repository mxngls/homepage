  • constellation

    I'm a contributor at microcosm.blue working on public, community-driven infrastructure. More precisely, I work on the Constellation project:

    Constellation is a self-hosted JSON API to an atproto-wide index of PDS record back-links, so you can query social interactions in real time. It can answer questions like:

    1. How many people liked a liked a bluesky post?
    2. Who are all the bluesky followers of an identity?
    3. What are all the replies to a Frontpage submission?
    4. What are all the sources of links to an identity?
    5. and more
