constellation

I'm a contributor at microcosm.blue working on public, community-driven infrastructure. More precisely, I work on the Constellation project: 

Constellation is a self-hosted JSON API to an
atproto-wide index of PDS record back-links, so
you can query social interactions in real time.
It can answer questions like:

* How many people liked a liked a bluesky post? 
* Who are all the bluesky followers of an identity?
* What are all the replies to a Frontpage submission?
* What are all the sources of links to an identity? 
* and more
